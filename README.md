  <h1>♿ Web Accessibility & WCAG Compliance</h1>
  <h2>Redesign of ASM Climútua Website</h2>

  <h2>📘 About the Project</h2>

  <p>This project was developed as part of a <strong>Master’s Dissertation</strong> focused on <strong>Web Accessibility for People with Visual Disabilities</strong>.</p>

  <p>The main objective is to analyze how compliance with the <strong>Web Content Accessibility Guidelines (WCAG 2.1)</strong> impacts the navigation experience of users with:</p>
  <ul>
    <li>Blindness</li>
    <li>Low vision</li>
    <li>Color vision deficiency (color blindness)</li>
  </ul>

  <p>Starting from an existing real-world website (ASM Climútua), the platform was <strong>redesigned and reimplemented</strong> to address accessibility barriers identified through technical evaluation and direct user involvement.</p>

  <h2>🎯 Project Goals</h2>

  <ul>
    <li><b>Evaluate accessibility issues</b> in an existing website</li>
    <li><b>Apply WCAG 2.1 (Levels A and AA)</b> in a practical context</li>
    <li><b>Improve usability</b> for screen reader and keyboard users</li>
    <li><b>Validate improvements</b> through testing with visually impaired users</li>
    <li>Demonstrate that accessibility goes beyond technical compliance</li>
  </ul>

  <h2>🧠 What Was Done</h2>

  <h3>🔍 Accessibility Evaluation</h3>
  <ul>
    <li>Automatic evaluation with Axe DevTools, WAVE and AccessMonitor</li>
    <li>Manual testing using keyboard navigation and screen readers</li>
    <li>Heuristic accessibility evaluation</li>
    <li>User testing with 6 participants with visual disabilities</li>
  </ul>

  <h3>🎨 Design & Prototyping</h3>
  <ul>
    <li>Accessibility-first design approach</li>
    <li>Color contrast and typography validation</li>
    <li>Light and dark mode support</li>
    <li>Adjustable font size</li>
    <li>Responsive layouts (mobile, tablet and desktop)</li>
    <li>High-fidelity prototyping using Figma</li>
  </ul>

  <h3>🚧 Development</h3>
  <ul>
    <li>Semantic HTML5 structure</li>
    <li>ARIA roles and attributes</li>
    <li>Fully keyboard-accessible navigation</li>
    <li>Dynamic content management with JavaScript</li>
    <li>Accessible form validation and feedback</li>
    <li>Persistent user preferences using <code>localStorage</code></li>
  </ul>

  <h2>🧪 User Validation & Results</h2>

  <p>
    After implementing all accessibility improvements, a final validation phase was conducted
    with the same users involved in the initial evaluation.
  </p>

  <ul>
    <li>Improved navigation and orientation using screen readers</li>
    <li>Clearer content structure and hierarchy</li>
    <li>Better usability of menus, filters and forms</li>
    <li>Contrast and text size adjustments benefiting low-vision users</li>
    <li>Identification of usability issues not detected by automated tools</li>
  </ul>

  <p>
      Accessibility compliance improved not only technical correctness, but also overall usability
      and user satisfaction.
  </p>
